Final Project Instructions: Full-Stack PHP Web System Development, CRUD Operations, and InfinityFree Deployment

Target Output & Project Scope

Develop, connect, and deploy a complete, functional web-based application or information system with full PHP back-end functionality and complete CRUD (Create, Read, Update, Delete) operations connected to a MySQL/MariaDB database on InfinityFree—accompanied by an annotated System User Guide and an RBIM-style Promotional Video Presentation.

I General Instructions

For your Final Project, you are required to build a complete, dynamic web-based application or information system (not static HTML pages) powered by a PHP back-end and a relational database to store, retrieve, update, and delete records. You must complete the following three major development phases plus final presentation deliverables:

1

Database Creation

Design and build your relational project database using either XAMPP (MySQL/MariaDB with phpMyAdmin) or MySQL Server.

2

PHP Back-End & CRUD

Develop full server-side logic in PHP (PDO or MySQLi) with user authentication, validation, and complete Create, Read, Update, and Delete operations.

3

InfinityFree Deployment

Deploy your complete PHP web system and MySQL database online using InfinityFree (htdocs/) so it is live via a public URL.

Expected Final Output

Complete web-based app/system with PHP back-end

Phase 01

Part 1. Database Creation

You may choose either of the following approaches to create your local database. Choose only one method, depending on your available tools and development environment.

Required Tools (Option A)

XAMPP (PHP 8.x + MariaDB/MySQL) Web Browser (Google Chrome, Firefox, Edge) Visual Studio Code or another code editor

Step 1. Install XAMPP

  1. Visit the official Apache Friends website: https://www.apachefriends.org/
  2. Download the XAMPP installer compatible with your operating system.
  3. Run the installer.
  4. Select the following components:
    Apache MySQL (MariaDB) PHP phpMyAdmin
  5. Complete the installation and open the XAMPP Control Panel.

Step 2. Start Apache and MySQL

  1. Open the XAMPP Control Panel.
  2. Locate Apache and click Start.
  3. Locate MySQL and click Start.
  4. Make sure both services are running (highlighted green).

Step 3. Open phpMyAdmin

  1. Open your web browser.
  2. Enter the following URL and press Enter:
    http://localhost/phpmyadmin
  3. The phpMyAdmin interface should appear.

Step 4. Create Your Database

  1. In phpMyAdmin, click the New option on the left panel.
  2. Enter your database name (Example: student_management_system).
  3. Select the collation utf8mb4_general_ci if available.
  4. Click Create. Your database should now appear in the left panel.
Important: Use lowercase letters and underscores for database names. Avoid spaces and special characters.

Step 5. Create Your Database Tables

  1. Click the database you created and locate the Create table section.
  2. Enter the table name, specify the number of columns, and click Create.
  3. Define the necessary fields and their data types (Example: students table):
Field Data Type Description
id INT Primary key (Enable AUTO_INCREMENT)
student_number VARCHAR(20) Student number
first_name VARCHAR(100) First name
last_name VARCHAR(100) Last name
email VARCHAR(150) Email address
created_at TIMESTAMP Date created

Set id as the PRIMARY KEY, enable AUTO_INCREMENT for the id field, and click Save.

Step 6. Insert Sample Records

  1. Select the students table.
  2. Click the Insert tab.
  3. Enter sample student information and click Go.
  4. Repeat until you have at least five sample records.

Step 7. Verify Your Database

  1. Click the students table.
  2. Select the Browse tab to check if records were saved.
  3. Review the table structure under the Structure tab.
Expected Result: Your database should contain the required tables, properly defined fields, primary keys, and sample records.

Required Tools (Option B)

MySQL Community Server MySQL Workbench Visual Studio Code or another code editor

Step 1. Download & Install MySQL

  1. Visit https://dev.mysql.com/downloads/
  2. Download MySQL Installer for your OS and run it.
  3. Select MySQL Server and MySQL Workbench.
  4. Choose default port 3306 and create a root password.
Important: Remember your MySQL username and password. You will need these credentials when connecting your PHP application.

Step 2. Open MySQL Workbench

  1. Launch MySQL Workbench.
  2. Locate the MySQL connection created during installation.
  3. Click the connection and enter your root password.
  4. Wait for the SQL Editor to open.

Step 3. Create Your Database

Open a new SQL query tab, enter the commands below, and click the lightning icon or press Ctrl + Enter:

CREATE DATABASE student_management_system;
USE student_management_system;

Step 4. Create Your Table

CREATE TABLE students (
    id INT AUTO_INCREMENT PRIMARY KEY,
    student_number VARCHAR(20) NOT NULL,
    first_name VARCHAR(100) NOT NULL,
    last_name VARCHAR(100) NOT NULL,
    email VARCHAR(150),
    created_at TIMESTAMP DEFAULT CURRENT_TIMESTAMP
);

Step 6. Retrieve & Verify Records

SELECT * FROM students;

Step 7. Verify Database Structure

SHOW TABLES;
DESCRIBE students;

Make sure that the database and table were successfully created.

Expected Result: Your MySQL Server should contain the database, table structure, primary key, and sample records.
Phase 02

Part 2. PHP Back-End Functionality & CRUD Operations

Build a complete web-based application or information system with full PHP back-end functionality so users can authenticate, submit forms, and perform complete Create, Read, Update, and Delete (CRUD) operations against your MySQL database.

Step 1. Prepare Your PHP Project Folder

Open Visual Studio Code, create a folder for your system inside C:\xampp\htdocs\ (e.g., student-management-system), and organize your back-end and front-end files: 

student-management-system/
│
├── index.php              # Landing / Login page
├── login_process.php      # PHP session authentication
├── logout.php             # Session destroy
├── dashboard.php          # System overview & metrics
├── students.php           # READ: Display records
├── add_student.php        # CREATE: Insert handler
├── edit_student.php       # UPDATE: Edit handler
├── delete_student.php     # DELETE: Remove handler
│
├── config/
│   └── database.php       # PDO / MySQLi connection
│
├── assets/
│   ├── css/
│   ├── js/
│   └── images/
│
└── database/
    └── student_management_system.sql

PHP System Architecture Breakdown

  • config/database.php — Centralizes PDO or MySQLi database credentials and error handling.
  • index.php / dashboard.php — Provides user entry, session protection, and dashboard summaries.
  • students / add / edit / delete — Implements server-side form processing and prepared SQL queries for CRUD.
  • database/*.sql — Holds your exported SQL schema & seed data for InfinityFree import.

Note: InfinityFree natively supports PHP 8.x and MySQL/MariaDB out of the box—making PHP PDO or MySQLi the recommended back-end stack for seamless deployment.

Steps 2 – 4. PHP Database Connectivity, Testing & CRUD Handlers

Inspect the PHP PDO implementation files below. Click any tab to view and copy production-ready prepared statement examples.

config/database.php (PHP PDO) 
<?php

$host = "localhost";
$dbname = "student_management_system";
$username = "root";
$password = "";

try {

    $conn = new PDO(
        "mysql:host=$host;dbname=$dbname;charset=utf8mb4",
        $username,
        $password
    );

    $conn->setAttribute(
        PDO::ATTR_ERRMODE,
        PDO::ERRMODE_EXCEPTION
    );

} catch (PDOException $e) {

    die("Database connection failed.");

}

?>
Code Purpose
$hostDatabase server address (localhost locally, or InfinityFree MySQL Hostname in production)
$dbnameName of your database
$usernameDatabase username
$passwordDatabase password
new PDO()Establishes a secure UTF-8 database connection
try-catchCatches and handles possible connection errors gracefully
Important: For a local XAMPP installation, the default credentials are root with an empty password (""). When deploying to InfinityFree in Part 3, you will update these four variables with your vPanel MySQL credentials.

PHP Prepared Statements for CREATE, UPDATE & DELETE 
<?php
require_once "config/database.php";

// 1. CREATE (add_student.php)
if ($_SERVER["REQUEST_METHOD"] === "POST" && isset($_POST["create"])) {
    $stmt = $conn->prepare("INSERT INTO students (student_number, first_name, last_name, email) VALUES (?, ?, ?, ?)");
    $stmt->execute([
        trim($_POST["student_number"]),
        trim($_POST["first_name"]),
        trim($_POST["last_name"]),
        trim($_POST["email"])
    ]);
    header("Location: students.php?status=created");
    exit;
}

// 2. UPDATE (edit_student.php)
if ($_SERVER["REQUEST_METHOD"] === "POST" && isset($_POST["update"])) {
    $stmt = $conn->prepare("UPDATE students SET student_number = ?, first_name = ?, last_name = ?, email = ? WHERE id = ?");
    $stmt->execute([
        trim($_POST["student_number"]),
        trim($_POST["first_name"]),
        trim($_POST["last_name"]),
        trim($_POST["email"]),
        intval($_POST["id"])
    ]);
    header("Location: students.php?status=updated");
    exit;
}

// 3. DELETE (delete_student.php)
if (isset($_GET["delete_id"])) {
    $stmt = $conn->prepare("DELETE FROM students WHERE id = ?");
    $stmt->execute([intval($_GET["delete_id"])]);
    header("Location: students.php?status=deleted");
    exit;
}
?>

Using PDO Prepared Statements (prepare() + execute()) protects your back-end against SQL Injection attacks.

Phase 03

Part 3. Hosting and Deployment Using InfinityFree

After completing and testing your PHP web application locally, deploy it online for free using InfinityFree so it is accessible through a live public website URL (.infinityfreeapp.com, .rf.gd, or custom domain) rather than only through localhost.

Required Materials: Completed PHP web system Database backup file (.sql) Free InfinityFree account Free InfinityFree subdomain (e.g. yourapp.infinityfreeapp.com)
1

Prepare Your Project & Export Database (.sql)

Open your project folder in Visual Studio Code, remove unnecessary/temporary files, verify case-sensitive file paths (InfinityFree runs on Linux servers where Dashboard.php differs from dashboard.php), and export your database backup (e.g., student_management_system.sql):

Via XAMPP / phpMyAdmin

  1. Open http://localhost/phpmyadmin
  2. Select your project database.
  3. Click the Export tab.
  4. Select Quick as the export method and SQL as format.
  5. Click Export and save the .sql file.

Via MySQL Workbench

  1. Open MySQL Workbench & connect to server.
  2. Select Server → Data Export.
  3. Select your project database.
  4. Choose Export to Self-Contained File.
  5. Specify filename/location and click Start Export.
2

Create an Account & Hosting Account in InfinityFree

Visit https://www.infinityfree.com/, sign up/log in to the Client Area, click Create Account, choose a free subdomain (e.g., yourproject.infinityfreeapp.com), and open the Control Panel (vPanel).

3

Upload Your Web Application to htdocs

  1. In InfinityFree Client Area or Control Panel (vPanel), open File Manager (Monsta FTP) or connect using an FTP client like FileZilla using your FTP credentials from Account Details.
  2. Open the htdocs folder (InfinityFree's web root directory—do not upload outside htdocs).
  3. Delete the default index2.html placeholder file inside htdocs.
  4. Upload your project files (or upload a ZIP archive under 10 MB and click Extract, or upload folders directly via FileZilla) so your entry file (index.php) sits directly inside htdocs/.
✓ Correct InfinityFree Structure 
htdocs/
├── index.php
├── dashboard.php
├── students.php
├── config/
│   └── database.php
└── assets/
✗ Avoid Nested Folder Inside htdocs 
htdocs/
└── student-management-system/
    └── index.php
# Causes unwanted subdirectory URL
InfinityFree Upload Tip: InfinityFree enforces a 10 MB maximum single-file upload limit on web servers. Keep assets optimized and use FileZilla FTP if uploading large project folders.
4

Create a MySQL Database in InfinityFree (vPanel)

Your local database does not transfer automatically. Open your InfinityFree Control Panel (vPanel) → Databases → MySQL Databases, enter a short database name (e.g., studentdb), and click Create Database. InfinityFree automatically assigns your account username and password to it.

Required Information InfinityFree vPanel Example
MySQL Host Namesql305.infinityfree.com (NEVER use localhost!)
MySQL Database Nameif0_38492015_studentdb
MySQL User Nameif0_38492015
MySQL PasswordYour InfinityFree Hosting Account Password (found in Client Area → Account Details)
5

Import Your Local Database into InfinityFree phpMyAdmin

In vPanel → MySQL Databases, locate your newly created database in the Current Databases list and click phpMyAdmin (or Admin). Inside phpMyAdmin, select your if0_XXXXXXX_dbname database on the left, open the Import tab, choose your exported .sql file, and click Go / Import.

Important: Before importing, remove any CREATE DATABASE ...; or USE ...; statements at the top of your .sql file if phpMyAdmin reports a privilege error, since InfinityFree restricts creating databases via SQL queries.
6

Update Your Database Connection Settings

Compare Local XAMPP vs. Production InfinityFree configuration

7

Test Your Deployed Website

Open your InfinityFree subdomain URL in a browser, verify the homepage loads, test login/registration, perform Create, Read, Update, and Delete operations directly against the live InfinityFree MySQL database, verify all CSS/JS/image paths, and test responsiveness on both desktop and mobile devices.

8

Activate Free SSL Certificate (HTTPS)

In your InfinityFree Client Area, navigate to the Free SSL Certificates tab, click New SSL Certificate for your domain, configure automatic CNAME records (or wait for propagation), install the certificate, and verify secure access via https://yourproject.infinityfreeapp.com.

Part 5. Important Reminders

        


        

          

            

              
1. Build a complete web-based system

              
Static HTML/CSS templates without working PHP back-end scripts and database CRUD operations will not be accepted.

            

            

              
2. Do not submit the sample student table

              
The sample students schema in this guide is for demonstration only. Design tables tailored to your proposed system.

            

            

              
3. Test locally before InfinityFree upload

              
Verify every PHP form, session login, and CRUD action on XAMPP before uploading to htdocs/.

            

            

              
4. Use exact InfinityFree MySQL hostnames

              
Never leave $host = "localhost" on InfinityFree—use your assigned sqlXXX.infinityfree.com hostname.

Your instructor must be able to test your live InfinityFree website, read your annotated User Guide, and watch your RBIM-style promo video.

Maintain local copies of all PHP source files, your .sql export, User Guide PDF, and video file.

            

            

              
8. Be prepared for live defense & Q&A

              
Every group member must be ready to explain the PHP CRUD code, SQL queries, and InfinityFree deployment setup.
